# Stage 02 — Tooling Setup

This folder documents a reproducible Python project setup for the stock-volatility forecasting project. The exercise uses a Python 3.11 Conda environment, a standard data science folder scaffold, environment variables loaded from a private `.env` file, a reusable configuration helper, a Jupyter notebook that verifies the environment and runs a small NumPy calculation, and a frozen `requirements.txt` so the setup can be recreated. Only dummy credentials are used, and `.env` is excluded from Git.
